# 陪肝小助手 · 视频跟跑助手 1.0.10

陪肝小助手是一款 Windows 桌面视频工具。它让攻略视频保持置顶，通过全局快捷键控制播放，并将与视频同步的弹幕投影到桌面。

1.0.8 内置 [Bilibili 线程撕裂者](https://github.com/MrTangLuyao/Bilibili-thread-ripper) 2026.10.8.1，默认启用。通过多路分段下载及 CDN 选择改善 B站视频缓冲；无需另装 Chrome 插件或脚本管理器。

保留 1.0.7 的小窗层级维护。开启「置顶」时，小窗会维护显示层级，不抢走正在使用的程序的键盘焦点；隐藏、最小化、设置弹窗打开或关闭置顶时停止维护。独占全屏显示仍需改用窗口模式。

保留 1.0.6 的小窗上沿中间拖动区域。左右边、底边和四角继续用于等比例缩放。

保留 1.0.5 的鼠标侧键快捷键。可录入侧键1（Mouse4 / XButton1）和侧键2（Mouse5 / XButton2），也支持 Ctrl、Alt、Shift 加侧键。保存后通过后台鼠标监听控制视频。

保留按键录制和小窗比例缩放；同次启动中再次进入小窗时保留调整后的宽度。

保留 1.0.3 的设置弹窗遮挡修复、1.0.2 的纯视频小窗与比例适配，以及 1.0.1 的菜单关闭闪退修复。

## 启动

解压 Windows 便携包，双击 `PeiganAssistant.exe`。请保留同目录的所有文件。便携包包含 .NET 运行时，无需安装开发工具。

电脑需要 Microsoft Edge WebView2 Runtime。若启动提示缺少它，可从 [Microsoft 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 获取 Evergreen Runtime。

## 使用

1. 在上方地址栏粘贴 B 站网址或完整 BV 号，点击「打开」。也可以点击「本地视频」。
2. 首次在网页中播放视频。需要高清画质时，请自行通过 B 站正常登录。
3. 点击「跟跑小窗」，拖动上沿中间移动窗口；也可拖动画面移动。拖动左右边、底边或四角调整大小，保持视频比例，无标题栏。开启鼠标穿透时需先关闭穿透才能拖动。小窗内使用快捷键控制播放；默认按 `Ctrl+Alt+I` 切换回完整界面，或按 `Ctrl+Alt+R` 恢复完整窗口并关闭鼠标穿透。
4. 使用全局快捷键控制视频；在「设置」中调整窗口透明度或改键。
5. 点击「弹幕：开」。软件读取当前 B 站页面已经收到的弹幕，并按播放进度投影到桌面。
6. 「设置」中可以选择显示器、投影顶部位置、高度、字号、持续时间和不透明度。

建议原神使用窗口化或无边框窗口。独占全屏可能挡住桌面置顶窗口。

如果切回原神后小窗消失，先确认陪肝小助手「置顶：开」，再检查原神的「设置 > 图像 > 显示模式」，可切换窗口模式进行对比。管理员权限和窗口置顶是两个独立问题：在 PeiganAssistant.exe 或你创建的快捷方式上选择「以管理员身份运行」，只改变启动权限，仍使用同一套设置。游戏以管理员权限运行且快捷键失效时，可先退出陪肝小助手再以管理员身份启动，并由你确认 Windows 权限提示；权限一致也不代表所有游戏输入模式都已兼容。

## B站视频加速

打开 B站视频后，在「更多 > B站加速设置…」调整线程撕裂者。默认使用上游的「大陆 CDN + 自动线程数」，先保留这一设置。面板中的速度、线程和缓冲数据由加速器实际统计。小窗中先按 `Ctrl+Alt+R` 恢复完整界面，再打开菜单。

陪肝小助手使用独立浏览器配置，Chrome 插件的设置不会自动同步。如果你曾在 Chrome 中调整 CDN 或接管模式，需要在陪肝小助手内重新设置。加速器设置按网站域名保存，退出后保留。

如遇视频兼容问题，可在加速设置中尝试「兼容模式」，或在「设置 > 弹幕与播放」取消「启用线程撕裂者」，保存后退出并重新打开陪肝小助手。关闭加载不清除已保存的加速器设置。

加速效果取决于网络和视频服务器，不能保证所有卡顿都会消失。此功能针对视频数据缓冲；游戏占用 GPU、视频解码或整个窗口卡顿需分别定位。登录、画质和观看权限仍由 B站决定。

内置脚本固定为上游提交 `0302b345cdfe367ac599b52dc6874e3f7967e220`，随陪肝小助手更新；不自动下载并执行远端更新。遵循 MIT 许可证，原始脚本、版权声明与完整许可证位于 `Assets/vendor/btr/`。

## 默认快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Alt+Space | 播放 / 暂停 |
| Ctrl+Alt+Left / Right | 快退 / 快进 5 秒 |
| Ctrl+Alt+Up / Down | 提高 / 降低倍速 |
| Ctrl+Alt+I | 跟跑小窗 / 展开 |
| Ctrl+Alt+T | 开关视频窗口鼠标穿透 |
| Ctrl+Alt+D | 开关桌面弹幕 |
| Ctrl+Alt+H | 显示 / 隐藏窗口 |
| Ctrl+Alt+PageUp / PageDown | 上一集 / 下一集（网页需要提供按钮） |
| **Ctrl+Alt+R** | **恢复完整窗口并关闭鼠标穿透，固定恢复键** |

改键：打开「设置 > 全局快捷键」，点击要修改的按键框，看到「请按快捷键…」后直接按下组合键，最后点击「保存设置」。不需要打字。支持 Ctrl、Alt、Shift 组合和功能键等；Win 组合不支持，会提示重录。`Esc` 取消本次录入，保留之前的值。按键重复不会误触保存或关闭设置。

鼠标侧键：点击按键框后，将指针留在框内按侧键。可先按住 Ctrl、Alt 或 Shift 再按侧键；显示「鼠标侧键1」或「鼠标侧键2」后保存。绑定生效时，该组合用于陪肝小助手，并拦截正常窗口消息中的侧键按下和释放，防止同时触发网页后退/前进；未绑定的组合保持原有行为。设置期间暂停侧键控制，方便重新录入。

如果鼠标驱动已将侧键改成宏或其他按键，需要在驱动中恢复为标准侧键，才能识别为 Mouse4 / Mouse5。其他软件的鼠标监听或游戏自己的原始输入可能影响侧键行为，无法像键盘热键一样自动检查跨软件占用。

如果快捷键重复、占用固定恢复键，或已被其他软件占用，陪肝小助手会提示并保留原配置。若恢复键被占用，鼠标穿透不会启用。也可以双击系统托盘中的陪肝小助手图标恢复窗口。

设置弹窗打开期间，普通全局热键暂时释放，便于录入原有组合；保存或取消后重新注册。未处于录入状态时可按 `Esc` 取消设置，或按固定的 `Ctrl+Alt+R` 将设置弹窗带到前面。

## 弹幕来源

- B 站：正常播放时自动捕获当前页面已经接收的弹幕响应。初次加载请保持网页弹幕开关开启。
- 本地 XML：「更多 > 导入 XML 弹幕」，选择与当前视频匹配的 B 站 XML 文件。支持滚动、逆向滚动、顶部和底部弹幕。
- 「更多 > 测试弹幕投影」只用于检查投影区域，显示内容明确标记为测试弹幕。
- 弹幕与视频时间轴同步。暂停时冻结，快退后可以重播；快进时丢弃过期弹幕，避免集中刷屏。
- 密集弹幕会限流；不播放代码弹幕和高级特效弹幕。
- 若网页尚未返回弹幕、网站限制访问或格式改变，软件不能保证获得全部弹幕。状态栏显示实际读取数量，也可使用 XML 导入。

## 进度与本地数据

网页视频进度每 15 秒保存，退出时也会保存。通过「更多 > 最近视频 / 恢复进度」重新打开；不会在你打开其他网页时强制跳到历史位置。本地文件本版不保存历史进度。

配置、进度、独立浏览器配置保存在 `%LOCALAPPDATA%\YingBan`。软件不读取已有浏览器的 Cookie，不读取游戏内存，也不控制游戏按键。网页请求遵循原网站的登录和播放限制。

## 已确认范围

本版包含视频跟跑与弹幕投影。AI 定位、自动对话、肝度报告和今日运势不在本项目功能范围。

常规顶层 HTML5 视频可控制。跨域 iframe 播放器、DRM 内容和不同网站专用播放逻辑不保证兼容。本地格式取决于系统 WebView2 解码能力。

## 从源码构建

安装 .NET 10 SDK，在源码根目录执行：

```powershell
dotnet run --project tests/YingBan.Tests
dotnet run --project tests/desktop/DesktopTests.csproj
node --test tests/browser/bridge.test.cjs
dotnet run --project tests/browser/BrowserSmoke.csproj
dotnet run --project tests/browser/BrowserSmoke.csproj -- --btr-only
dotnet run --project tests/browser/BrowserSmoke.csproj -- --btr-only --btr-disabled
dotnet run --project tests/integration/Integration.csproj -- --acceleration-settings-only
dotnet run --project tests/integration/Integration.csproj -c Release
dotnet build src/YingBan.App/YingBan.App.csproj -c Release
dotnet publish src/YingBan.App/YingBan.App.csproj -c Release -r win-x64 --self-contained true -o dist/YingBan
```

测试报告见 [验证记录](verification.md)。构建无需原神客户端。浏览器和桌面集成测试会创建测试窗口；请顺序执行，避免全局快捷键互相占用。
